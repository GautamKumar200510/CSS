### **Practice Qs**

**Recreate the following elements using given CSS:**

* Create a div & **3 sibling divs** inside it.

* **For the outer div**, set the following styling:

  * `height: 200px`
  * `width: 70px`
  * `border: 2px solid black`

* **For the inner divs**, set the following styling:

  * `height: 50px`
  * `width: 50px`
  * `border: 2px solid black`
  * `margin: 10px`
  * Make the inner divs **circular** in shape.
  * Give them individual colors: **red, yellow, and green**.
